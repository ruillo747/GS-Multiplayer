# GS Multiplayer

**Играйте в обычный одиночный мир Minecraft Java 1.16.5 с друзьями через интернет — без своего сервера и без лишних программ.**

Тип подключения — как в Open2Online / e4mc: хост открывает мир и получает адрес `IP:порт`,
друг вставляет его в «Прямое подключение» и заходит. **Соединительный сервер не нужен вообще.**
Языки: русский + английский (определяется по языку игры).

```
Хост:  Esc → GS Multiplayer → Открыть в сеть → Открыть
       → адрес IP:порт в чате и в буфере обмена
Друг:  Сетевая игра → Прямое подключение → вставить адрес → играть
```

## Как это работает

1. **Хост** открывает свой одиночный мир: мод публикует встроенный сервер Minecraft на порту (по умолчанию 25575).
2. Мод **автоматически пробрасывает порт на роутере** — UPnP → NAT-PMP → PCP (протоколы перебираются сами).
3. Мод определяет **внешний IP** (STUN, а если UDP заблокирован — по HTTPS) и отправляет в чат **два адреса**:
   `ваш_IP:порт` — для друзей из интернета, `192.168.x.x:порт` — для друзей в той же Wi‑Fi сети.
   Интернет-адрес сразу копируется в буфер обмена.
4. **Друг** подключается обычным «Прямым подключением» — на его стороне **мод не нужен**.
5. Если роутер не пробился — мод покажет локальный адрес и подсказку; правила брандмауэра можно
   пересоздать кнопкой в настройках.

Дополнительно: чекбокс «Разрешить друзьям без лицензии» (мир открывается в offline-режиме),
быстрое подключение по адресу прямо в меню мода с историей адресов, проверка обновлений.

## Быстрый старт (двое друзей)

1. Оба ставят Minecraft **1.16.5** + Fabric Loader (Java 17). Мод нужен **только хосту**.
2. Хост: в мире **Esc → GS Multiplayer → Открыть в сеть → Открыть**.
3. Хост отправляет адрес другу (уже в буфере обмена).
4. Друг: **Сетевая игра → Прямое подключение** → вставить адрес → **Играть**.

Максимум игроков ограничен только вашим «железом» (ванильный лимит мира).

## Сборка из исходников

```bash
./gradlew build        # результат: build/libs/gsmultiplayer-<версия>.jar
```

## Структура

```
src/main/java/com/gsmultiplayer/
├── client/             # клиентская точка входа, GsText (RU/EN), GuiUtil
│   └── gui/            # меню, быстрый коннект, «Открыть в сеть», настройки, диагностика
├── config/             # config/gsmultiplayer.json
├── mixin/              # кнопки в титульном экране и меню паузы, снятие проброса
├── network/portmap/    # UPnP IGD + NAT-PMP + PCP (чистый Java, без зависимостей)
├── p2p/                # STUN (внешний IP)
├── update/             # проверка GitHub Releases
└── util/               # лог, правила брандмауэра Windows
```
