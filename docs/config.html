Генератор конфига мода

Заполните поля — получите готовый config/gsmultiplayer.json.

Файл кладётся в .minecraft/config/gsmultiplayer.json (в Modrinth App: инстанс → Open Folder → .minecraft/config/). Мод создаёт этот файл сам при первом запуске — генератор нужен, чтобы сразу указать рабочий сервер и не лезть в настройки игры.
