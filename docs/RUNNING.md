# Запуск для игроков

## Что нужно

- Minecraft Java Edition **1.16.5**
- [Fabric Loader](https://fabricmc.net/use/installer/) (установка в один клик, отдельный профиль в лаунчере)
- Мод `gsmultiplayer-<версия>.jar` из [Releases](https://github.com/ruillo747/GS-Multiplayer/releases)
- **Соединительный сервер не нужен.** Мод нужен только тому, кто открывает мир; друзья подключаются обычным Minecraft

## Установка

1. Установите Fabric Loader для 1.16.5 (галочки: версия игры 1.16.5, loader 0.16.x, Java 17).
2. Скопируйте jar мода в `.minecraft/mods/`:
   - Windows: `%APPDATA%\.minecraft\mods\`
   - Linux: `~/.minecraft/mods/`
   - macOS: `~/Library/Application Support/minecraft/mods/`
3. Запустите игру с профилем **fabric-loader-1.16.5**.

Modrinth App: вкладка **Mods → Remove** (старый gsmultiplayer) → **+ Add from file** → новый jar.

## Как открыть мир другу (хост)

1. Зайдите в свой одиночный мир.
2. **Esc → GS Multiplayer → «Открыть в сеть»**.
3. Выберите режим игры и порт (по умолчанию 25575) → **Открыть**.
4. Мод сам пробросит порт на роутере (UPnP/NAT-PMP/PCP) и определит ваш внешний IP.
5. В чат придут два адреса, а интернет-адрес сразу попадёт в буфер обмена:
   - `ваш_внешний_IP:порт` — для друзей из интернета;
   - `192.168.x.x:порт` — для друзей в той же Wi-Fi сети.
6. Отправьте адрес другу (Discord, Telegram — куда угодно).

## Как подключиться (друг)

1. Minecraft → **Сетевая игра → Прямое подключение**.
2. Вставьте адрес `IP:порт` → **Подключиться**. Всё.
   - Мод на стороне друга **не нужен**.
   - Либо: поставьте мод и вставьте адрес в поле быстрого подключения в меню GS Multiplayer
     (мод помнит последние 5 адресов).

## Настройки

- **Порт LAN** — порт публикуемого мира (25575 по умолчанию; при занятости «Открыть в сеть» пробует соседние).
- **Разрешить друзьям без лицензии** — мир открывается в offline-режиме: заходит кто угодно с адресом.
- **Автопроброс порта (UPnP)** — включён по умолчанию; выключите, если пробрасываете порт вручную.
- **Правила брандмауэра** — пересоздаёт правила Windows Firewall для Java (фикс «никто не может подключиться», Windows, нужен UAC).
- Остальные — интерфейс и обновления.

## Если не подключается

| Симптом | Решение |
|---|---|
| «Соединение отклонено» у друга | Хосту нажать «Правила брандмауэра»; проверить, что друг вводит адрес **с портом** |
| Адрес только локальный (192.168.x.x) | Роутер не поддерживает/блокирует UPnP — включите UPnP в роутере или пробросьте UDP+TCP порт вручную; после ручного проброса адрес будет `ваш_IP:порт` |
| Друг из той же Wi-Fi | Используйте второй адрес из чата (192.168.x.x:порт) — работает всегда |
| Хост вышел из мира | Адрес перестаёт действовать — откройте мир заново и отправьте свежий адрес |

## Диагностика

**GS Multiplayer → Диагностика**: версия мода, состояние мира, журнал и кнопка «Скопировать лог».
Лог помогает разобраться в любой проблеме — приложите его, когда пишете в поддержку.
