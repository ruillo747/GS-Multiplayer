# Запуск для игроков

## Что нужно

- Minecraft Java Edition **1.16.5**
- [Fabric Loader](https://fabricmc.net/use/installer/) (установка в один клик, отдельный профиль в лаунчере)
- Мод `gsmultiplayer-<версия>.jar` из [Releases](../../releases)
- Доступный signaling-сервер (свой или публичный) — адрес вписывается в настройках мода

## Установка

1. Установите Fabric Loader для 1.16.5 (галочки: версия игры 1.16.5, loader 0.16.x).
2. Скопируйте jar мода в `.minecraft/mods/`.
   - Windows: `%APPDATA%\.minecraft\mods\`
   - Linux: `~/.minecraft/mods/`
   - macOS: `~/Library/Application Support/minecraft/mods/`
3. Запустите игру с профилем **fabric-loader-1.16.5**.

## Первый запуск

Мод автоматически:

- создаст `config/gsmultiplayer.json` (адрес signaling-сервера, relay, настройки соединения);
- сгенерирует ваш **GS ID** вида `GS-7K2M9QX4` — это ваш адрес для друзей;
- определит язык интерфейса по языку Minecraft (русский/английский);
- подключится к signaling-серверу и проверит обновления.

## Хост: открыть мир для друзей

1. **Одиночная игра** → загрузите ваш мир (любой, с любыми модами клиента).
2. Нажмите **Esc → GS Multiplayer → Открыть комнату**.
3. При желании поменяйте название комнаты и режим игры, включите читы.
4. Нажмите **Открыть комнату** — появится код комнаты.
5. Отправьте код друзьям («Скопировать код») или пригласите друзей из списка (по GS ID).

Мир продолжает работать как обычно — вы играете в нём же.

## Гость: подключиться

1. В главном меню: **GS Multiplayer → Подключиться по коду** (или примите приглашение из списка друзей).
2. Введите код → **Подключиться**.
3. На экране подключения мод согласует P2P-соединение (до нескольких секунд), при неудаче автоматически перейдёт на Relay.
4. Игра сама подключится к миру хоста — как к обычному серверу.

## Управление друзьями

- **GS Multiplayer → Друзья**: добавление по GS ID, зелёный индикатор — друг онлайн, ● — друг сейчас в комнате.
- Кнопка **Позвать** отправляет приглашение игроку (он увидит его в главном меню GS Multiplayer).
- Список хранится **только у вас**: `.minecraft/config/gsmultiplayer/friends.json`.

## Настройки

**GS Multiplayer → Настройки**:

| Параметр | Описание |
|---|---|
| Никнейм | имя в комнатах и приглашениях (по умолчанию — ник Minecraft) |
| Signaling-сервер | `ws://host:35500` или `wss://host/...` |
| Адрес/порт Relay | обычно пусто — берётся с сервера; задаётся вручную для своего relay |
| Локальный LAN-порт | порт публикации мира (25575 по умолчанию) |
| Режим разработчика | техническая панель в диагностике |
| Кнопки меню | показать/скрыть кнопки мода в главном меню и меню паузы |

## Диагностика

**GS Multiplayer → Диагностика**:

- сводка: версия, состояние сервера, фаза;
- **GS Multiplayer Log** — журнал событий (`Room created`, `Player found`, `P2P negotiation`, `P2P connected`, ...), копируется кнопкой;
- режим разработчика добавляет панель по каждому соединению:

```
Player:  OPEN  |  Latency: 42 ms  |  Relay: Standby  |  Packet loss: 0%
```

- `Relay: Standby` — relay не используется (идёт P2P); `Active` — трафик через relay.

## Частые вопросы

**Не подключается, «Relay не настроен»** — администратор signaling-сервера не задал `RELAY_PUBLIC_HOST`/`RELAY_SECRET`. P2P при этом может работать; relay — нет.

**«В комнате нет мест»** — максимум 4 игрока (хост + 3 гостя).

**Высокий пинг в Relay-режиме** — relay в другой стране; разверните свой сервер ближе к игрокам.

**Антивирус/файрвол** — моду нужен исходящий UDP (P2P и relay). Исходящие порты обычно не блокируются; входящие слушать не требуется.
